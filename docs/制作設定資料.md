## 本人の設定資料（原文）

### 1. ゲームの概要
- タイトル： 文字型抜き
- どんなゲーム？： 砂糖菓子に刻まれた文字を、割らないように針で切り抜くゲーム。
- 面白さ・特徴： 緊張感のある型抜きと、難しい文字をきれいに切り抜けたときの達成感を楽しむ。

### 2. ゲームの内容
基本操作
- マウスや指で針を動かし、文字の輪郭に沿って切り抜く。
- 輪郭から外れると失敗し、砂糖菓子が割れる。
- 文字を完全に切り抜いて取り外せたら成功する。

文字の選択
- ランダムに文字を選んで型抜きに挑戦できる。
- 自分で好きな文字や言葉を入力し、その形を型抜きできる。
- 入力した文字を砂糖菓子に刻まれた型として表示する。
- 対応する文字の種類や入力可能な文字数などは、実現可能な範囲でClaudeが決める。

入れたい要素・演出
- 失敗時に砂糖菓子が割れる演出。
- 成功時に切り抜いた文字が外れる演出。
- 成功ランク・スコアによる評価。
- 砂糖菓子らしい質感と、型抜き中の緊張感を表現する。

### 3. 対応環境
- PCとスマートフォンの両方に対応する。
- ブラウザから遊べるゲームにする。
- PCはマウス、スマートフォンはタッチ操作に対応する。
- 画面サイズに応じてレイアウトを調整し、スマートフォンでも細かい操作がしやすいようにする。

### 4. 制作方針
- まず遊べる状態を最優先で作る。
- 細かい仕様・数値・実装方法は、ゲームのコンセプトに合うようにClaudeが決める。
- グラフィックや演出は、制作環境に合った方法でできるだけ充実させる。
- 仕様の矛盾や重大な問題があれば、実装前にまとめて報告する。
- 実装計画を作成し、私の確認後に制作を開始する。
- テストと修正は問題点をまとめて行い、不要なやり取りを減らす。
- 完成条件を満たしたら制作を終了し、最終チェック後の修正は1回にまとめる。

### 5. 最初に実装するもの
まずは、文字を選択または入力し、その文字の型抜きを実際に遊べる基本バージョンを目指す。
文字の形状生成、輪郭から外れた際の失敗判定、切り抜きの成功判定など、技術的に難しい部分は実現方法を検討する。自由入力に制約が必要な場合や、希望する機能の実現が難しい場合は、実装前に理由と代替案をまとめて提示する。
最初から機能を増やしすぎず、基本の型抜きが成立することを優先する。

## 技術的に難しい部分の実現方法（Claude）

### A. 文字の形をどう作るか
- 入力された文字を、見えないキャンバスに **太いフォントで大きく描き、ピクセルの形（白黒の型）として読み取る**。どの文字でもフォントに入っていれば同じ方法で形にできるので、文字ごとのデータを用意する必要がない
- その型の **輪郭（文字の外周と、「あ」「日」などの内側の穴のフチ）を線として取り出し**、砂糖菓子に「刻まれた溝」として描く
- 文字が離れた部品に分かれる場合（「川」「い」「ぎ」の濁点など）は、**部品ごとに別々に切り抜く**。全部の部品が外れたらクリア

### B. 輪郭から外れた判定（割れる）
- 溝の中心線からの距離で3段階にする
  - **溝の中（安全）**：そのまま切れる
  - **溝のフチ（危ない）**：切れるが「ヒビ」が少しずつ入る（ヒビゲージが増える。画面にも細いヒビが伸びる）
  - **溝の外**：その瞬間に割れて失敗
- ヒビゲージが満タンでも割れる。**速く動かしすぎてもヒビが入る**（型抜きの「焦ると割れる」緊張感。ゆっくり丁寧が正解になる）
- 指やマウスを離すのは自由。**置き直しは溝の上でだけ受け付け**、溝の外に置いたときは割らずに「ここには刺せない」と表示するだけにする（誤タッチで割れるのは理不尽なので）
- 指を速く動かしたときに途中を飛ばさないよう、前回の位置から今回の位置までを細かく区切って全部判定する

### C. 切り抜きの成功判定（外れる）
- 輪郭の線を細かい点に分け、**針が近くを通った点を「切れた」**にする
- 1つの輪郭の点が **ほぼ全部（98% 以上）切れたら、その輪郭はつながった**とみなす。1つの部品の輪郭（外周と内側の穴のフチ）が全部つながったら、その部品がポロッと外れる
- 小さな切り残しで永遠に終わらないのを防ぐため、残りがわずかなときは切り残しの場所を光らせて教える

### D. スマホで細かい操作をしやすくする
- **針は指の少し上に出す**（指で溝が隠れないように。オフセット量は設定で変えられる）。PC は針＝マウス位置
- 砂糖菓子は **1枚に1文字** を画面幅いっぱいに大きく出す（言葉を入力したら、1文字ずつ順番に挑戦）
- 溝の幅は画面の大きさに合わせて決め、スマホでもタッチの精度で届く幅にする
- 指をタッチしている間は画面がスクロール・ズームしないようにする

## 実装前に報告する仕様上の問題と対応案（Claude）

1. **言葉を1枚の砂糖菓子に並べると、スマホでは1文字が小さすぎて細かい操作ができない**（「細かい操作がしやすく」と両立しない）→ **1枚に1文字**、言葉は1文字ずつ順番に型抜きして、全部終わったら合計スコアと、抜いた文字を並べて見せる
2. **自由入力の制約**
   - **文字数は 1〜6 文字**（1文字あたり 30秒〜数分かかるため、それ以上は長すぎる）
   - **使える文字**：ひらがな・カタカナ・漢字・英数字・よく使う記号（！？♡☆ など）。空白は無視
   - **使えない文字**：絵文字（色つきで、フォントの形として輪郭が取れない）、フォントに入っていない文字。入力時に判定して「この文字は型にできません」と出す
   - **画数の多い漢字**（「鬱」など）は、線どうしの隙間が溝の幅より細くなり、溝がくっついて形が崩れる。輪郭の長さから **難しさ（★1〜5）を自動で出し、極端に複雑な文字は「難しすぎます」と断る**（上限は Phase 1 で実際に試して決める）
3. **「輪郭から外れると失敗」をそのまま即失敗にすると、スマホでは指の数ピクセルのブレで割れて理不尽になる** → 上の B の3段階（安全／危ない＝ヒビ／外＝割れる）にして、緊張感と遊びやすさを両立する
4. **文字の内側の穴（「あ」「日」「O」などの囲まれた部分）をどう扱うか** → 本物の型抜きと同じく **内側のフチも切る**（切らないと文字の形にならない）。内側の部分は文字といっしょには外れず、そのまま残る
5. **ランダムの文字がどれも同じ難しさだと面白くない** → ランダムは **かんたん／ふつう／むずかしい** を選んでから引く（かんたん＝「一」「口」「L」「O」など形が単純、ふつう＝ひらがな・カタカナ・簡単な漢字、むずかしい＝画数の多い漢字や曲線の多い文字）
6. **成功ランク・スコアの中身が決まっていない** → 1文字ごとに
   - **ていねいさ**（溝の中心からどれだけズレずに切れたか）
   - **ヒビの少なさ**（最後に残ったヒビゲージ）
   - **速さ**（目安時間より早いとボーナス。ただし速く動かすとヒビが入るので、急ぐほど危ない）
   - を合計して 0〜1000点、**ランク S／A／B／C**。文字の難しさでスコアに倍率をかける
7. **砂糖菓子の質感** → 画像素材なしで、キャンバスにノイズ（ざらつき・粒）、ほんのりした凹凸の陰影、縁の厚み、刻まれた溝の影を描いて作る。色はピンク・水色・黄色などの淡い色からランダム
8. **完成条件が決まっていない** → 下の「完成条件」を Claude 案として出す（本人確認で確定）
9. **保存** → ベストスコア・挑戦した文字の記録は公開版のみ localStorage に保存（検証用の file 表示では保存されない）。Phase 1 には入れない

## 完成条件（Claude 案）
1. ランダム（3段階）と自由入力（1〜6文字）のどちらでも、文字の型抜きを最初から最後まで遊べる
2. 溝から外れる・ヒビが満タンで割れて失敗、全部の部品が外れて成功、が正しく判定される
3. 失敗時に割れる演出、成功時に文字が外れる演出、ランクとスコアの表示がある
4. PC のマウスと、スマホ縦持ちのタッチの両方で、無理なく最後まで切り抜ける
5. 使えない文字・複雑すぎる文字を入力しても止まらず、理由を表示する

## 実装計画

### 画面構成
- **タイトル** → **文字を選ぶ画面**（「ランダム（かんたん／ふつう／むずかしい）」と「文字を入力」）→ **型抜き画面** → **結果画面**
- 型抜き画面：中央に砂糖菓子（円形の板）と刻まれた文字。上に文字・難しさ・時間・ヒビゲージ・何文字目か。針は小さな銀色の針の絵
- 結果画面：抜いた文字、ランク、スコアの内訳、「もう一度」「次の文字」「文字を選ぶ」

### Phase 1 — 基本の型抜きが遊べる版（最優先）
文字の入力（制約チェックつき）とランダム（3段階）、文字の形の生成・輪郭の取り出し・部品分け、針の操作（マウス／タッチ、スマホは指の上に針）、3段階の判定とヒビゲージ、切れた溝の表示、部品が外れる判定、成功・失敗の簡単な表示（演出は最小限）、スコアとランク、言葉の1文字ずつの進行
→ **本人が遊んで操作感を確認**（溝の幅・ヒビの入りやすさ・針のオフセットをここで調整する）

### Phase 2 — 質感と演出と音
砂糖菓子の質感（ざらつき・陰影・縁・色）、ヒビが伸びる表示、割れる演出（割れ目が走ってかけらが落ちる）、外れる演出（文字が少し浮いて持ち上がる・粉が舞う）、ランク発表の演出、緊張感の演出（ヒビが多いと画面が少し暗く・心音のような音）、WebAudio の効果音（削る音・ヒビ・割れる・外れる・ランク）
→ **本人が遊んで確認**

### Phase 3 — 仕上げと調整
タイトル画面、遊び方の説明、ベストスコアと挑戦記録の保存、難しさとスコアの調整、スマホ縦持ち・PC での表示確認
→ **最終チェック（問題点をまとめて報告 → 修正は1回）→ 完成条件を満たせば終了、公開は本人の判断**
